# ClipForge: notes for Claude Code

## What this is
SwiftUI iOS app (iOS 17+) that turns long game streams into 9:16 reels on the phone:
loud-moment + transcript-based moment finding, Whisper captions (Hindi and other Indian
languages), live styled preview, export to Photos. The user signs the unsigned IPA on his
iPhone with Feather.

## Hard constraints
- There is NO Mac. You cannot run xcodebuild, Xcode, or a simulator in this environment.
  The only compiler is GitHub Actions: `.github/workflows/build-ipa.yml` (macos-26, Xcode 26).
- The Xcode project is generated by XcodeGen from `project.yml`. Never commit a .xcodeproj.
  New .swift files go under `ClipForge/` and are picked up automatically.
- Dependency: `argmax-oss-swift` (product `WhisperKit`), from 1.1.1.
- Swift language mode 5.9, deployment target iOS 17. Liquid Glass goes through `glass()` in
  GlassKit.swift, guarded by `#if compiler(>=6.2)` + `#available(iOS 26.0, *)`. Keep that fallback.
- Do not change the bundle ID, runner, or package versions without saying why in the PR.

## How to work
1. Work on a branch, small focused commits.
2. Push, then check the Actions run for your branch. Fix compile errors until it is green.
   If you cannot read the workflow logs, stop and ask the user to paste the failing lines.
3. A green build is the minimum bar. You cannot test runtime behaviour, so end every task with
   a short "test on device" checklist for the user.
4. Prefer small diffs over rewrites. Explain trade-offs plainly.

## Architecture map
- EditorModel.swift: @MainActor @Observable editor state; import, moment analysis, preview rebuild, export.
- ReelRender.swift: ReelStyle, ReelState (thread-safe shared render state read every frame),
  custom AVVideoCompositing compositor. Core Image per frame: layout, backgrounds, punch zoom,
  hype meter, hook sticker, captions.
- Captions.swift: caption words/pages, TextKit caption renderer (Pill / Pop / Clean), per-script fonts.
- AudioAnalyzer.swift, AudioRange.swift: 0.1 s loudness bins, highlight windows, silence cutting, sample extraction.
- Transcriber.swift: actor wrapping WhisperKit (word timestamps).
- Moments.swift: Moment model, TextScorer (excitement lexicon, speech rate, repeats, punctuation),
  ShortShaper (cuts a moment at sentence boundaries: setup before the peak, payoff after).
- ClaudeRanker.swift: optional Anthropic API (user key in UserDefaults "anthropicKey"): findClips (whole transcript in
  15-min windows, LOUD marks; returns snapped clips with hook, title, post text, punch words) and fixCaptions.
- Transliterator.swift: Devanagari and Urdu script -> Roman Hinglish (port of PeakCut roman.py).
- Facecam.swift: Vision-based facecam detection + manual box editor. Stream layout = facecam top, gameplay bottom.
- Overlays.swift: watermark and "peak slam" bitmaps.
- LinkImporter.swift + helper/clipforge_helper.py: Kick/Twitch/YouTube links. The phone cannot run yt-dlp, so a
  small Python helper on the user's computer downloads (yt-dlp + ffmpeg) and the app pulls the MP4 over Wi-Fi.
- Ported from PeakCut (MIT, see THIRD_PARTY_NOTICES.md): romanisation, clip/caption prompts, sentence snapping,
  caption styles (Bounce/Hype/Clean with bundled OFL fonts in ClipForge/Fonts), hook box.
- Exporter.swift: composition building, video composition, export, save to Photos.
- GlassKit.swift (Theme, Segments, JobRow), TimelineStrip.swift, Panels.swift, ContentView.swift: UI.
  Design: graphite surfaces, hairlines, one lime accent, mono timecodes. Glass only over video.
- Background work never blocks the UI: EditorModel jobs (importJob, analysisJob, captionJob, exportJob,
  facecamJob) render inline in their section. Do not add modal progress overlays.

## Gotchas
- Two timelines: source time (original video) vs composition time (after silences are cut).
  Map with EditorModel.mapWords; transcripts are stored in source time.
- Core Image uses a bottom-left origin. The renderer is designed at 1080x1920; everything scales by k = width / 1080
  (preview renders at 540x960).
- Never block the main thread with file copies or AVAssetReader loops.
- Streams are usually Hindi/Hinglish; Whisper with language "hi" outputs Devanagari and sometimes Urdu script.
  Captions default to Roman Hinglish via Transliterator.roman.
- Analysis: quick pass (12 loudest stretches) runs after import; "Deep scan" transcribes everything and lets
  Claude read the whole transcript in 15-minute windows (PeakCut's approach).
